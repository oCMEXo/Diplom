# ADR-004: развёртывание в AWS

## Решение

Один EC2-инстанс с Docker Compose (API, collab, runner, Redis, Caddy с
HTTPS), база в RDS PostgreSQL, фронтенд в S3 за CloudFront. Это дешевле и
проще, а runner'у всё равно нужен Docker-демон, которого нет в Fargate.

| Критерий | EC2 + Compose (выбран) | ECS Fargate + ALB |
|---|---|---|
| Сложность | Низкая: одна машина, один compose-файл | Высокая: сервисы, задачи, балансировщик, IAM |
| Стоимость | Инстанс + RDS; без балансировщика | Плюс ALB и посекундная оплата Fargate |
| Запуск кода | Docker работает напрямую | Нужен отдельный EC2 всё равно |
| Масштабирование | Вертикальное (тип инстанса) | Горизонтальное |
| Для диплома | Хватает для демо и нагрузочных тестов | Избыточно |

## Последствия

Всё живёт на одной машине, её падение останавливает сервис, но данные в RDS и
локальные копии у клиентов сохраняются. В дипломе описываем переход на ECS
как путь расширения. Текущие цены и условия free tier стоит проверить перед
стартом.
